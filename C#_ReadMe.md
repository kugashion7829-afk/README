# C#の主な記述群
// ==================================================

## MonoBehaviour
    分類：クラス
    Unity上で利用できるCompornentとして設定する

## class
    設計図らしい…

## static
    実物を作らずに使える

## void 
    戻り値を返さない

## public
    外からアクセスできる

## private
    外から直接アクセスしにくくする

## Main()
    分類：メソッド
    コンソールアプリの開始地点

## Program 
    分類：クラス
    プログラム本体のクラス

<!-- 段落 -->

## using ～～　
    どの領域を使うのか指定する

    SystemであればSystem領域内にあるクラスを利用できる


### using UnityEngine 
    UnityEngineという領域を使用するという宣言

### using System 
    Systemという領域を使用するという宣言

<!-- 段落 -->

## console
    分類：クラス
    コンソールに関する機能を使用


### console.WriteLine()
    分類：メソッド
    コンソールに()内に格納されているものを一行表示する

### console.Write()
    分類：メソッド
    コンソールに()内に格納されているものを改行せず表示する

### console.ReadLine()
    分類：メソッド
    ユーザーが入力した値を受け取る
